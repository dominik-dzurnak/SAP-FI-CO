# SAP FI/CO Notes

Structured study notes on SAP Financial Accounting (FI) and Controlling (CO), built while preparing for SAP consulting work. These cover the core transactions, processes, and configuration concepts a functional FI/CO consultant works with day to day.

## 📂 Contents

| File | Covers |
|---|---|
| `transaction-codes.md` | Key FI/CO transaction codes, grouped by process area |
| `ap-ar-process.md` | Accounts Payable and Accounts Receivable process flow |
| `cost-center-accounting.md` | Cost Center Accounting basics and reporting |
| `spro-config-notes.md` | Notes on navigating SPRO/IMG for FI/CO configuration |

## 🎯 Scope

These notes focus on:
- **FI**: General Ledger, Accounts Payable, Accounts Receivable
- **CO**: Cost Center Accounting, cost element structure
- **Configuration**: how FI/CO settings are organized in SPRO

## 📌 Note

This is a personal study reference, not official SAP documentation. It reflects concepts I've worked through in coursework and self-study. For authoritative details, always refer to SAP Help Portal or official SAP training material.
